## Текущее состояние — реализовано
Проверенная основа: 1.0 / Android Bundle Version Code 2, внутреннее тестирование Google Play. Пользователь сообщил размер AAB 33.1 МБ, успешную сборку без красных ошибок, принятие Console без ошибок/предупреждений и успешное обновление на телефоне. AAB не был доступен для независимого анализа; точная привязка артефакта к SHA и его хеш не установлены.

- Две машины; последовательное чередование по кругу. Случайного выбора и третьей машины пока нет.
- DirtCleaner удаляет альфа-канал рабочей текстуры мягкой кистью. Жесты, начатые на UI, не очищают машину. Завершение удаляет остаток грязи.
- Звук сопровождает удаление новой грязи и затухает. SoundToggleUI сохраняет настройку.
- Before по удержанию показывает исходную грязь, отпускание/выход возвращают чистый вид. Before и Next скрыты до завершения через CanvasGroup.
- Процент, мятная полоска и подсказка используют один прогресс. Swipe to clean скрывается при первом удалении грязи; после завершения — Hold Before to compare.
- Next сохраняет индекс следующей машины и перезагружает SampleScene. Restart сейчас повторяет текущую машину, НЕ смену.
- PlayerPrefs сохраняет CarWashASMR.CurrentCarIndex и CarWashASMR.SoundEnabled. Очистка не сохраняется.
- PrivacyPolicyButton находится снизу справа в SafeArea и открывает фиксированный URL во внешнем браузере.
- Гараж, ручные цвета кнопок, значки звука и длинная подложка приняты; без причины не заменять. CameraWidthFit сохраняет ширину, BackgroundFit заполняет кадр через Mathf.Max и correctY.

Смены, часы, итоговый экран, статистика смен, деньги и улучшения НЕ реализованы. Согласованный переход к сменам описан в плане.
