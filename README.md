# Car Wash ASMR

Небольшая вертикальная 2D-игра для Android.
Одна машина для текущего прототипа.
Управление одним пальцем, офлайн.

## Окружение

- Unity: 6000.3.10f1.
- Шаблон: 2D Built-In Render Pipeline.
- Система ввода: Input System.
- Рабочая сцена: Assets/Scenes/SampleScene.unity.
- Проверенный телефон: Samsung Galaxy A57, Android 16.

## Что работает

- Очистка грязи мышью и пальцем.
- Подстройка ширины игрового кадра.
- Отображение процента очистки.
- Завершение на 98% с удалением оставшейся грязи.
- Перезапуск текущей сцены кнопкой.
- Звук при удалении новой грязи.
- Переключение звука с сохранением выбора.
- Блокировка очистки для жестов, начатых на UI.

## Скрипты

- DirtCleaner — очистка, прогресс, завершение и разделение ввода.
- CameraWidthFit — сохранение ширины игрового кадра.
- LevelRestart — перезагрузка текущей сцены.
- SafeAreaUI — размещение UI внутри Screen.safeArea.
- CleaningProgressUI — текст прогресса и завершения.
- CleaningAudio — воспроизведение и затухание звука очистки.
- SoundToggleUI — переключение звука и сохранение настройки.

## Текущие параметры

- Brush Radius Pixels: 24.
- Completion Threshold Percent: 98.
- CleaningAudio Max Volume: 0.05.
- CameraWidthFit Reference Orthographic Size: 8.
- CameraWidthFit Reference Aspect: 0.5625.

## Подтверждённые проверки

- Сборка и запуск на Android.
- Очистка, завершение и повторное прохождение.
- Несколько перезапусков подряд.
- Сворачивание и возвращение в приложение.
- Сохранение настройки звука после нового запуска.
- Разделение жестов кнопок и очистки.

## Ограничения

- Проверен один Android-телефон.
- Дополнительный нижний отступ UI подобран вручную.
- Очистка пока использует кисть с чётким краем.
- Промежуточная очистка после закрытия приложения не сохраняется.
- Нет дополнительных машин, перехода между ними и оформления гаража.
- Требования публикации Google Play ещё не проверены.

## Работа с двух устройств

Перед работой получить последние изменения через Pull.
После работы сохранить файлы, сделать Commit и Push.
Использовать одинаковую версию Unity на обоих устройствах.
