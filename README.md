# Car Wash ASMR

Документация сверена: 2026-10-23.

Небольшая вертикальная 2D-игра для Android от Anvumi Games: очистка автомобиля одним пальцем, звук и сравнение до/после. Две машины; после второй последовательность повторяется. Офлайн-цикл проверен на исторической Android-сборке, а не на всех последующих версиях автоматически.

Текущие задачи, ограничения и идеи — в [DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md). README описывает устройство проекта, настройки и историю проверок; план не должен дублировать всю эту историю.

## Механика и сохранение

- Мягкая кисть постепенно удаляет грязь мышью или пальцем. Прогресс считается по доле удалённой исходной непрозрачности.
- В принятой настройке завершение происходит на 98%: остаток грязи удаляется, UI показывает 100%.
- Звук сопровождает удаление новой грязи, затем затухает. Настройка звука сохраняется.
- Жест, начатый на UI, не используется для очистки.
- Next после завершения выбирает следующую пару спрайтов и перезагружает сцену; после второй машины цикл повторяется. Restart повторяет текущую машину.
- Сохраняются выбранная машина и настройка звука. Промежуточная очистка и состояние завершения не сохраняются: новый запуск начинается с 0%.
- После мойки удержание Before показывает исходную грязь; отпускание и выход за границы кнопки возвращают чистую машину без изменения прогресса.
- CameraWidthFit сохраняет ширину кадра. BackgroundFit использует Mathf.Max для равномерного заполнения вида фоном и correctY для вертикального смещения; часть фона может обрезаться. Это не гарантия проверки всех экранов.

## Принятый интерфейс

Новый UI применён и одобрен пользователем в Unity Editor. Повторная Android-проверка после последних изменений не подтверждена.

- Restart — светлая стрелка на компактной полупрозрачной подложке снизу слева. Звук — сверху справа, значки icon_sound_on/icon_sound_off. Значки используют Preserve Aspect, не принимают raycast; слой значка звука исправлен на UI.
- Before и Next скрыты и не перехватывают касания до завершения мойки; появляются после неё и снова скрываются после Next/Restart. CanvasGroup скрывает графику и блокирует взаимодействие, но сами объекты остаются активными для обновления скриптов.
- Актуальные цвета кнопок и ui_button_background_long.png выбраны пользователем. Не заменять их автоматически оформлением Restart.
- Сверху — только процент, тонкая мятная полоска и подсказка, без общей панели. Процент и заполнение используют DirtCleaner, полоска не интерактивна и не принимает raycast.
- До очистки: Swipe to clean. После первого фактического удаления грязи подсказка скрыта, даже если округлённое число ещё 0%. После завершения: 100%, полная полоска и Hold Before to compare. После новой загрузки сцены — начальное состояние.

## Скрипты

Игровые скрипты находятся в Assets/Scripts:

- DirtCleaner — очистка, прогресс, завершение, разделение ввода.
- CameraWidthFit — ширина кадра; BackgroundFit — заполнение фоном.
- LevelRestart — перезагрузка сцены; SafeAreaUI — UI внутри Screen.safeArea.
- CleaningProgressUI — процент и Slider; CleaningHintUI — состояния подсказки.
- CleaningAudio — звук и затухание; SoundToggleUI — звук, значок и сохранение выбора.
- CarSequence — машины, сохранение выбора, переход и видимость Next.
- BeforeAfterPreview — сравнение по удержанию и видимость Before.

Инструменты в Assets/Editor уже применены к сцене:

- SoundButtonSetup.cs — Car Wash ASMR → Setup Sound Button.
- ActionButtonsSetup.cs — Car Wash ASMR → Setup Before and Next Buttons.
- MinimalProgressHUDSetup.cs — Car Wash ASMR → Setup Minimal Progress HUD.

Не прикреплять их к объектам и не запускать повторно без необходимости: команды могут перезаписать ручные настройки. Это код редактора, не Android-плеера. Исправление логики подсказки не требует повторного запуска команды HUD.
