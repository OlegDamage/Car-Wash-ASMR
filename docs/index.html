Car Wash ASMR - Privacy Policy

Developer: Anvumi Games. Contact: anvumi.games@gmail.com.

About the game

Car Wash ASMR is an offline car-cleaning game for Android. The current game does not require an in-game account and does not include advertising, in-app purchases, chat, or user-uploaded content.

Local gameplay information

The game reads touch or mouse input to control cleaning. Its gameplay code processes this input on the device and does not record a gesture history or send it to a developer server. The game saves the selected car and sound setting locally using Unity PlayerPrefs. Partial cleaning progress is not saved.

Engine services and release verification

The reviewed project has Unity Analytics, Ads, Purchasing, cloud diagnostics, and performance reporting disabled in its service settings. The next release candidate also removes the legacy analytics module and disables the serialized submitAnalytics setting. These changes require a new build and testing. Network behavior of the distributed release has not yet been verified; a final statement about automatic collection and sharing will be completed before this draft is used as a release policy.

Google Play

Downloading and updating the game through Google Play is governed by Google's own terms and privacy policy. Google Play may process account, device, installation and diagnostic information as described in its policies. This is separate from the local gameplay settings described above.

This website and external links

The in-game policy button opens a web browser. This page contains no advertising or analytics scripts, external fonts, or embedded media. It is hosted on GitHub Pages. GitHub logs visitors' IP addresses for security purposes under the GitHub Privacy Statement. Browser and hosting processing is separate from offline gameplay.

Retention and deletion

Local car and sound settings are kept until the app's local data is cleared or the app is uninstalled, subject to Android backup and restore behavior. Clearing app storage resets these settings. If you email us, your email provider and ours process the message; we use the information you provide to answer your request and retain it only as needed for that purpose or legal obligations. Contact us to request deletion of correspondence, subject to those obligations.

Audience and changes

The intended audience is teenagers aged 13 and above and adults. The game is not marketed specifically to children under 13. Future features, advertising, or data practices require an updated policy and applicable disclosures before release.
